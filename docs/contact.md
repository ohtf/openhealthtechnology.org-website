# Contact

OHTF works in the open wherever it can, so public questions are best asked publicly, where the answer helps the next person too. For anything else, email us.

## General enquiries

**[hello@openhealthtechnology.org](mailto:hello@openhealthtechnology.org)**

Partnerships, hosting and support, bringing a project to OHTF, press, or anything else.

## About a specific project

Open an issue on that project's repository. The [projects page](projects/index.md) links to each one. This is the quickest way to reach the people who maintain it.

## Proposing a project

Read [bring a project](projects/bring-a-project.md), then start a discussion on [GitHub](https://github.com/orgs/ohtf/discussions), or email us if you would rather talk privately first.

## Security vulnerabilities

**Do not use public issues.** Report privately to **[security@openhealthtechnology.org](mailto:security@openhealthtechnology.org)** or through GitHub private vulnerability reporting. See the [security policy](community/security.md).

## Code of conduct

To report behaviour that breaks the [code of conduct](community/code-of-conduct.md), email **[conduct@openhealthtechnology.org](mailto:conduct@openhealthtechnology.org)**.

## This website

Spotted a mistake? Every page has an edit link, or [open an issue](https://github.com/ohtf/openhealthtechnology.org-website/issues) on the website repository.

## On GitHub

All OHTF code lives at **[github.com/ohtf](https://github.com/ohtf)**.
